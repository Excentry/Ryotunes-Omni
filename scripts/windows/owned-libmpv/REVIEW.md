## Separate compiler/runtime gate

The 15 library snapshots are not the complete provenance inventory for a Windows binary. `libstdc++.a`, libgcc, MinGW-w64 CRT/startup objects and any other compiler-supplied objects need their exact versions, source provenance, licenses and applicable runtime exceptions checked against the pinned image and final link. Recording an archive hash does not establish an exception or fulfill source obligations. Windows OS DLL imports must be distinguished from bundled runtime code.

For selected DLL SHA-256 `6a6ac973ecb495b6799b32d221fdf357f212f9cbd65bc01599670ed6b9d13f56` from run `41150745596`, the pinned image is `ghcr.io/btbn/ffmpeg-builds/win64-gpl@sha256:572cc7bc0974ebe2e5fd5f82c49e68c07942c6858098fd04f8daa23e3dc4dd2c`. The MinGW source is commit `7213d719fe344553aa24fef7cc7dedee4940d594`, not the earlier `57b595039040eaa15bece85b7cc71d952281b269` source record. The issue evidence reports that all 349 headers differing between those revisions match `7213d719` in the image. `sources.lock.json` now pins the complete `7213d719` source archive, and the three MinGW notice hashes are unchanged at that revision. The original run artifact and its `source-inputs.tar.gz` remain immutable; a new source companion must include this additional archive and corrected provenance.

The private evidence bundle `evidence-6a6ac973-gapless-gcc.tar.gz` (asset SHA-256 `b20d35fbbef78fcfdc0df0900782da3211144c0618f7785d8b43b18dd2bb06e0`) maps all 101 linked GCC-family members to one source each in GCC 16.2.0: 10 by DWARF compile-unit names, 71 by unique source name, six by libtool archive rename order and 14 by MinGW configure defaults. All mapped source files carry Runtime Library Exception text. The review maps all 16 applied crosstool-NG patches and reports that none touches a linked `.c`, `.cc` or `.S` file. This is an exact source-path map, but not an object reproduction: libstdc++ objects have no DWARF, patch 0004 changes headers that may be compile inputs, patches 0022 and 0026 change configure inputs, and the patch identity relies on the compiler's reported crosstool-NG version. No runtime-exception failure is confirmed. Preserve this as a technical confidence gap, not as an unmapped-source claim or legal clearance.

The same private evidence reports all 63 linked MinGW members mapped to one source path through `Makefile.in`, with no unresolved members and no explicit Cephes, Moshier, Wine or LGPL marker in the selected sources. Ten members use new or changed files versus the earlier MinGW revision; their source paths and per-file grants are recorded in the private review. The mapping does not enumerate consumed headers, compile flags or generated source, and the upstream Cephes FIXME remains in the archive root.

Five original GCC/MinGW notice texts are fixed by revision and SHA-256 in `notice-inputs.lock.json`, verified during preparation and packaging, included in the source archive's recipe, and delivered under `licenses/toolchain/`. The three MinGW texts are pinned to `7213d719` for the selected DLL; their bytes and hashes match the earlier `57b595` copies. They include GPLv3, GCC Runtime Library Exception 3.1, MinGW's root and runtime notices, and winpthreads' MIT/BSD notices. These are notice inputs, not complete GCC source snapshots or proof that the runtime exception applies to every linked member. See `licenses/toolchain/README.md` for the remaining provenance limits and unresolved Cephes/Wine references.

The GCC exception permits eligible target-code combinations with independent modules under their own terms; it does not remove the GPL obligations of mpv/FFmpeg/Rubber Band. Verify each applicable runtime grant and the effective toolchain patches before relying on that exception. Retain sources for anything requiring them; do not assume all compiler-produced material has the same grant.

## Delivery arrangement

1. The user designated this DLL as official for Windows in issue #44 and separately authorized public release of the standalone DLL/source pair. This authorization does not certify legal compliance or approve an application release. The package guard checks known required notices; it is not proof that all native source files have received per-file review.
2. The prerelease `libmpv-6a6ac973-r2` carries the Windows ZIP, the companion corresponding-source archive and `SHA256SUMS.txt`. The original Actions source archive remains immutable; the public companion contains the corrected source-input archive, exact MinGW source, GCC 16.2.0 source, crosstool-NG source/patches, and the GCC runtime map. Verify the release manifest after download.
3. The source companion is hosted beside the matching binary in the same durable public release. It does not rely on Actions artifact retention or upstream links alone. Its README records source hashes, preparation steps and limits.
4. The source map covers all 101 GCC-family members and the evidence maps all 63 MinGW members; no runtime-exception incompatibility was confirmed. The GCC runtime objects were not rebuilt and compared, some header/configure patches may affect compilation, the toolchain container was not rebuilt from the included sources, and the native review remains a notice superset rather than a complete per-file audit. Preserve these as explicit technical/legal review limits; do not label them as a confirmed violation or as complete clearance.
5. If shipping Ryotunes Omni with this GPL candidate, include the corresponding application sources and build/install scripts needed for that combined work under compatible terms, with any required installation information. This standalone DLL/source release does not cover the application's obligations. Review installer/EULA/store restrictions; do not add restrictions conflicting with recipient rights.
6. A user-directed asset publication does not close every validation gate. The Windows hosted runner passed MSI/NSIS install and uninstall; Windows Sandbox/manual GUI validation, a complete per-file review, and application-level GPL distribution review remain separate work. This review is engineering evidence, not legal advice or a compliance certification.
